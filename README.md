# Devang Dileep — Portfolio Website

> Personal portfolio website built as part of **23CSE113 – User Interface Design (Project Phase-1)**

---

## Overview

This website serves as my personal portfolio, showcasing my introduction, educational background, projects, and contact details. The goal of this project is to demonstrate frontend development skills using only **HTML and CSS**.

---

## Pages

### Home (`index.html`)
Introduction and overview of who I am, with links to other sections of the portfolio.

### Education (`pages/education.html`)
A structured table of my academic background including institution names, qualifications, graduation years, and scores.

### Projects (`pages/projects.html`)
A showcase of projects I have worked on, highlighting the technologies used and outcomes.

### Contact (`pages/contactme.html`)
Contact form and links to my email, GitHub, and LinkedIn profiles.
